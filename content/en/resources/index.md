## Phishing
Tools and resources to help identify, avoid, and report phishing attempts and suspicious websites.

- :PageLink{title="PhishTank" url="https://www.phishtank.com/"} Community-powered database for identifying and reporting phishing websites
- :PageLink{title="APWG" url="https://apwg.org/"} Anti-Phishing Working Group offering resources to combat phishing globally
- :PageLink{title="URLVoid" url="https://www.urlvoid.com/"} Tool to check a website's reputation and detect malicious activities.
- :PageLink{title="OpenPhish" url="https://openphish.com/"} Automatic phishing detection and intelligence feed service.

Quick links to report phishing
- :PageLink{title="Google Safe Browsing" url="https://getaegis.app/"} Report suspicious websites to Google Safe Browsing
- :PageLink{title="Microsoft Security Intelligence" url="https://www.microsoft.com/en-us/wdsi/support/report-unsafe-site-guest"} Microsoft's platform for reporting phishing and malicious URLs

## Malware Analysis
Free tools and platforms for analyzing suspicious files, detecting malware, and maintaining system security.

- :PageLink{title="VirusTotal" url="https://www.virustotal.com/gui/home/upload"} Online scanner for analyzing files and URLs for malware and suspicious content.
- :PageLink{title="Malwarebytes" url="https://www.malwarebytes.com/"} Malware protection and removal software for home and business use.
- :PageLink{title="ClamAV" url="https://www.clamav.net/"} Open-source antivirus engine for detecting malware and malicious files.
- :PageLink{title="Sandboxie" url="https://sandboxie-plus.com/"} Tool for running applications in an isolated sandbox environment.
- :PageLink{title="Hybrid Analysis" url="https://www.hybrid-analysis.com/"} Free malware analysis platform for analyzing suspicious files and URLs
- :PageLink{title="Any.run" url="https://any.run/"} Interactive malware analysis tool for analyzing and sharing results in real time.

## Network Security
Essential tools for monitoring network traffic, detecting vulnerabilities, and securing your connections.

- :PageLink{title="Wireshark" url="https://www.wireshark.org/"} Network protocol analyzer for monitoring and troubleshooting network traffic.
- :PageLink{title="OWASP ZAP" url="https://www.zaproxy.org/"} Open-source penetration testing tool for identifying web application vulnerabilities
- :PageLink{title="Snort" url="https://www.snort.org/"} Intrusion detection system for real-time traffic analysis and threat prevention.
- :PageLink{title="Shodan" url="https://www.shodan.io/"} Search engine for discovering devices and systems exposed to the internet.
- :PageLink{title="SecurityHeaders" url="https://securityheaders.com/"} Analyze a website's HTTP security headers for vulnerabilities
